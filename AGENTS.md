# Repository working instructions

When a change implements, partially implements, redesigns, or invalidates an item in
`src/docs/agent-capability-roadmap.md`, update that roadmap in the same work:

- update the item's status and last-updated date;
- record concrete files, tests, or evaluation evidence;
- append a short entry to the implementation log;
- do not mark an item complete without satisfying its acceptance criteria.

Unrelated maintenance does not require a roadmap update.
